# Una - Centralized Club Management
Una is a centralized club management system designed to help RSOs around the world create their own custom portals.
This is a work-in-progress project with the ultimate goal of enabling the following:
### Goals
- Provide individual RSOs and student organizations with the ability to create their own portals through a centralized platform  
- Enable member management, payment gateway integration, event organization, and a point system within custom RSO portals  
- Allow customization so each RSO portal has a unique look and feel  
- Allow schools, universities, and communities to fork this repository and maintain their own private version of the application
